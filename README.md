# Unlimited Typing

> 把一段文字，逐字符打进任何一个禁止粘贴的地方。

**状态：v0.0.1 — 仓库初始化中（当前只有文档，尚无代码）**

---

## 1. 这是什么

Unlimited Typing（简称 **UT**）是一个 **Windows 桌面工具 + 自制 USB HID 硬件触发器**的组合项目。

你把一整段文本放进 UT 的输入框，按一下全局热键、或者按一下桌面上的物理按钮，
UT 就会像真人打字一样，逐字符地把这段文本"敲"进当前光标所在的输入框——
**即使那个输入框已经禁用了粘贴。**

## 2. 为什么需要它

大量网站/软件的输入框通过 JavaScript 拦截了 `paste` 事件，导致无法粘贴长文本。
但它们无法拦截"逐字符敲击"这种合法输入。UT 做的就是：

> 把「粘贴」翻译成「打字」。

## 3. 两种输出后端

| 后端 | 角色 | 能力边界 |
|---|---|---|
| **软件注入**（Unicode 直发，`VK_PACKET`） | **主力**：中文长文本 | 进不了提权窗口 / UAC 安全桌面 |
| **硬件打字**（STM32F103 自制 HID 键盘） | **兜底**：过 UIPI / 锁屏 / 极端场景 | 只能输出 ASCII 键码，打不出汉字 |

> 为什么中文长文本不能走硬件？因为 HID 键盘只能发送"第几个键被按下"，
> 汉字必须依赖输入法把拼音转成字——那是"模拟打字"，不是"注入文本"。
> 详见 [设计文档](docs/DESIGN.md)。

## 4. 架构总览

```
触发层（PC / 板子）        引擎层（PC, C++）              后端层
─────────────────         ─────────────────────         ───────────────────────
板载物理按钮  ─┐           ┌──────────────────┐          ┌─ UnicodeInjector（主力）
全局热键      ─┼─────────▶ │  UT Core         │─IInjector┼─ HidTypist（M5 之后）
托盘菜单      ─┘           │  文本→分段→打字   │          └─ KeyCodeInjector（兼容兜底）
                          │  进度/暂停/续打   │
                          │  目标窗口校验     │
                          └──────────────────┘
```

## 8. 使用边界（重要）

本项目仅用于：

- 个人自动化与效率提升
- 无障碍辅助（输入困难人群）
- 在自己有权限的系统中批量填表、批量录入
- 自己开发的软件的自动化测试

**明确不支持、也不接受以下用途**：

- 绕过游戏反作弊系统
- 绕过安全软件 / EDR
- 批量注册、灌水、刷单等违反平台规则的滥用
- 任何未经授权向他人设备注入输入的行为
